# CyberSafe PK - Cybersecurity Awareness Platform

![React](https://img.shields.io/badge/React-18-61dafb.svg)
![TensorFlow.js](https://img.shields.io/badge/TensorFlow.js-4.10-ff6f00.svg)
![Tailwind CSS](https://img.shields.io/badge/Tailwind-3.3-38bdf8.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

A modern cybersecurity awareness and education platform for Pakistan, built with React and TensorFlow.js for ML-powered threat detection.

## 🚀 Features

- 🔒 **Threat Detection**: ML-powered phishing and malware detection
- 📚 **Education**: Cybersecurity awareness content
- 🎯 **Interactive**: File scanning and analysis
- 📊 **Dashboard**: Security insights and recommendations
- 🌐 **Localized**: Pakistan-focused cybersecurity content

## 🛠️ Tech Stack

- **Frontend**: React 18
- **ML**: TensorFlow.js
- **Styling**: Tailwind CSS
- **UI Components**: Radix UI
- **Animations**: Framer Motion
- **Routing**: React Router

## 📦 Installation

```bash
npm install
npm start
```

## 🏗️ Project Structure

```
src/
├── components/    # React components
├── pages/         # Page components
├── models/        # TensorFlow.js models
└── utils/         # Utility functions
```
